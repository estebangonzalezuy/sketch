# Chart

Chart animado: trayecto con flechas, barras o puntos. Dibuja en canvas 2D en unidades de diseño.

- **Origen:** tool nueva. Su lenguaje visual sale de los charts del blog de Inception Labs.
- **Entradas:** ninguna.
- **Datos:** una línea por punto: `etiqueta | x | y | sobretítulo | nota | lado`, con lado `l` o `r`, más `u` o `d` para subir o bajar la etiqueta. En `bars`, `x` solo ordena.
- **Límites:** los valores del preset de Inception se leyeron a ojo de una imagen: son aproximados y solo sirven de ejemplo.
