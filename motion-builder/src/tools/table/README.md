# Tabla

Tabla comparativa con filas en cascada y columna destacada.

- **Origen:** tool nueva, basada en la tabla de benchmarks del blog de Inception Labs.
- **Entradas:** ninguna.
- **Datos:** primera línea con encabezados, `# Grupo` para abrir una sección y `*valor` para marcar el mejor de la fila.
- **Límites:** las columnas tienen el mismo ancho. El preset de Inception resume la tabla original, sin todas sus filas, y es solo un ejemplo.
